# Lo que dicen las naciones cuando hablan de población
Este repositorio contiene el código para replicar la figura de la nota "Lo que dicen las naciones cuando hablan de población", publicada en [Novedades ALAP](https://www.alapop.org/2025/11/lo-que-dicen-las-naciones-cuando-hablan-de-poblacion/), con base en los datos de Jankin, S., Baturo, A., y Dasandi, N. (2017). United Nations General Debate Corpus 1946–2024 (V13). Harvard Dataverse. https://doi.org/10.7910/DVN/0TJX8Y.
